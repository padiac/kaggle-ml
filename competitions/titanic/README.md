# Titanic - Machine Learning from Disaster

## Usage

### Local
1. Ensure data is in `../../data/titanic/` (contains `train.csv`, `test.csv`).
   You can use `../../scripts/kaggle_download.sh titanic` to download it.
2. Run training:
   ```bash
   python train.py
   ```
3. Check `submission.csv`.

### Kaggle Config
This code handles `/kaggle/input` automatically. Just upload the code.
